Lesson 18: First Conditional

A2+ → B1 English Lesson · ~45 minutes

Warm-up

🗣️ Warm-up

  • What will you do if it rains this weekend?
  • What will happen if you practise volleyball every single day?
  • If you could go anywhere in the world, where will you go?

Presentation

Grammar Focus: First Conditional

We use the first conditional to talk about real and possible situations in the future — things that can actually happen.

Structure: If + present simple, will + base verb

Important: We NEVER use will in the if clause.

The order can change: The if clause can come first or second.

If we practise hard, we will win the tournament. ✅

We will win the tournament if we practise hard. ✅

If I finish my painting, I will enter the competition.

If she doesn't come to training, the coach will be disappointed.

If it rains, I won't go to the park.

Common mistakes to avoid
❌ If I will study, I will pass. ✅ If I study, I will pass.
❌ If she will come, we will start. ✅ If she comes, we will start.

Practice

Complete each first conditional sentence. Use the verb in brackets.

Each sentence has one mistake. Write the correct sentence.

1. If I will win the match, I will be very happy.

2. If she comes early, she will helps me with the painting.

3. I won't go if it will be too cold outside.

4. If we will practise more, we will improve.

5. If he don't hurry, he will miss the bus.

6. She will be upset if we will forget her birthday.

7. If it will snow, school will close.

8. If you will ask nicely, she will help you.

9. We will lose if we won't play as a team.

10. If I will finish early, I will call you.

Match the if clause to the correct result.

1. If we train every day this week, a. she will be the best player on the team.
2. If it rains tomorrow, b. we will feel confident before the match.
3. If she keeps improving at this rate, c. I will call you immediately.
4. If I hear any news, d. the match will be moved indoors.
5. If the weather is nice tomorrow, e. we will have the picnic outside.
6. If she practises every day, f. she will improve quickly.
7. If we lose this match, g. we will still be proud of our effort.
8. If you don't study for the test, h. you will fail.
9. If I finish my homework early, i. I will watch a film.
10. If they arrive late, j. they will miss the bus.

Answers: 1-b, 2-d, 3-a, 4-c, 5-e, 6-f, 7-g, 8-h, 9-i, 10-j. Say each full sentence aloud.
