Homework Practice

Use the verb in brackets in the correct present perfect form.

Put the words in the correct order to make a sentence.

1. never / have / cooked / I / a / meal / big

2. just / has / the / she / left / office

3. for / lived / they / years / have / three / here

4. ever / you / have / seen / film / this / ?

5. yet / not / arrived / has / bus / the

6. since / knew / have / known / we / each / other / 2015

7. already / has / lunch / eaten / she

8. never / been / have / I / to / Italy

9. for / has / worked / company / this / he / years / ten

10. just / message / sent / has / a / she

Choose the best word to complete each sentence: ever, never, just, already, yet, for, since.

Write 6 sentences about your life using the present perfect. Try to include:

  • 2 sentences with ever or never
  • 2 sentences with just or already
  • 2 sentences with for or since
